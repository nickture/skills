# Почта

Почтовые клиенты поддерживают только часть HTML и CSS, и каждый по-своему, поэтому у писем свои правила вёрстки.

- **Письмо рассылки собрано из надёжного.** Без веб-шрифтов, полупрозрачных плашек и текста внутри картинок: половина почтовых клиентов их не покажет, а письмо из картинок недоступно экранному диктору и грузится медленно. `[complex-designer]`
