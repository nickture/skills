# Иконки

- **Иконки из одного набора и одного размера.** Все иконки берутся из одной библиотеки, у них один размер по умолчанию. Рядом с крупным текстом иконка крупнее, и обводка у неё пропорционально толще. У иконок одного размера рядом с текстом одного начертания одна толщина обводки, а начертание меняет её по правилу «Толщина обводки под текст рядом». Иконка из другого набора заметна сразу. `[dsc, nick]`
- **Обводка в покое, заливка в активном состоянии.** Заливка тяжелее обводки, поэтому выбранный пункт заметнее соседних. Оба состояния берутся из одного набора и одного размера, иначе выбор читается как подмена иконки. `[ui-skills, dsc]`
- **Толщина обводки под текст рядом.** При одном размере иконки обводка 2px рядом с полужирным текстом и 1.5px рядом с регулярным. У крупной иконки обводка пропорционально толще по правилу «Иконки из одного набора и одного размера». `[ui-skills]`
- **Оптическое выравнивание.** Геометрический центр не всегда выглядит центром: треугольник «play» сдвигается вправо, стрелка выравнивается по тексту, иконки в ряду подгоняются по видимому размеру. `[ui-skills, nick]`
- **У иконки со смыслом есть имя, декоративная скрыта от экранного диктора.** У кнопки-иконки без текста задан `aria-label`, у декоративной — `aria-hidden="true"`. На экране видны обе, диктор озвучивает только первую. `[dsc, ui-skills]`
- **Именование по смыслу.** `play`, не `triangle`; `close`, не `x`. `[dsc]`
- **Иконка ставится там, где помогает.** Иконка без очевидного смысла убирается. Неоднозначная иконка (QR, «поделиться») подписывается. Иконки либо у всех полей формы, либо ни у одного. `[nick]`
- **Где смысл критичен, символ дублируется текстом.** Иконку, эмодзи и знак каждый читает по-своему. Опасное, платное и необратимое подписывается словами. `[complex-designer]`
- **Действие в строке и на панели — иконкой.** Действие, которое повторяется в каждой строке таблицы или списка, и команда на панели инструментов показываются кнопкой-иконкой с подсказкой при наведении и `aria-label`: изменить, копировать, скачать, удалить. Ряд кнопок с подписями в каждой строке занимает больше места, чем сами данные, и заметнее их. Главное и важное действие экрана подписывается словами, иконка при нём ставится рядом с подписью. Иконка без подписи годится для действия с однозначной метафорой, остальные подписываются по правилам «Иконка ставится там, где помогает» и «Знакомая пиктограмма не берётся под другой смысл». `[nick]`
- **Иконка, одинаковая у всех строк, убирается.** Повторяющийся знак ничего не различает. Общий признак выносится в заголовок группы по правилу «[Общее для группы выносится за скобки](hierarchy.md)». `[nick]`
- **У понятия одно имя и одна иконка.** Два похожих показателя с похожими иконками путают. Близкие по смыслу пункты разводятся иконками или сливаются. `[nick]`
- **Знакомая пиктограмма не берётся под другой смысл.** Сердце с числом читается как лайки, лупа как поиск, «⋯» как «ещё». Переучить пользователя нельзя. `[nick, classics]`
- **Зарезервированные действия у своих иконок.** Крестик закрывает или скрывает, корзина удаляет, «+» добавляет, шеврон раскрывает. У одного значка одно действие: «+» не раскрывает список, шеврон есть только у раскрывающегося. Скрыть и удалить — разные действия. Крестик убирает из вида уведомление, фильтр или подсказку, но данных не удаляет, для удаления во всём проекте есть корзина. `[dsc, nick]`
- **Иконки одного оформления.** Все в кружке или все без, в одном списке один тип маркера. Иконка не распирает свою подложку. `[nick]`
- **Иконка не заменяет подписи в навигации новичка.** На десктопе боковое меню раскрыто с подписями: иконки наизусть знает тот, кто заходит каждый день. `[nick]`
- **Системные эмодзи проверяются на другой системе.** Эмодзи на разных платформах рисуются по-разному. Для делового интерфейса они заменяются схематичными иконками. `[nick, gstack]`
- **На малом размере упрощённый знак.** Логотип и иконка без мелких деталей и надписей на размере фавикона и аватарки. Знак проверяется в горизонтальном и вертикальном виде, без надписи и в ленте среди чужих аватарок. `[nick]`
