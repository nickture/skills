# Расхождения источников в интерфейсе

Здесь собраны места, где источники советуют разное, и что выбрано. Правило в скилле уже записано по выбранному варианту. Строка с пустой колонкой «Выбрано» — спор, который ещё не решён, и правило по нему не пишется, пока выбора нет.

| Вопрос                           | Источники                                                                                                                                                                                                                                                                                                                                 | Выбрано                                                                                                                      |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Длина строки                     | 60–75 знаков (ui-skills), 45–75 (gstack), до 80 (anthropic)                                                                                                                                                                                                                                                                               | 45–75, ориентир 65                                                                                                           |
| Интерлиньяж заголовка            | около 1.1 и `leading-tight` (ui-skills), 1.15–1.25 (gstack)                                                                                                                                                                                                                                                                               | 1.1–1.25; в Tailwind v4 `leading-tight` = 1.25, крупные `text-*` уже плотные                                                 |
| Трекинг                          | плотнее у крупного (ui-skills), не трогать трекинг ([baseline-ui](https://github.com/ibelick/ui-skills/tree/main/skills/baseline-ui)), не разряжать строчные (gstack)                                                                                                                                                                     | плотнее у крупного display, разрядка только у капса                                                                          |
| Капс-ярлыки                      | без капса (ui-skills); капс-ярлык с разрядкой над каждым заголовком и капс в ярлыках — шаблон (anthropic)                                                                                                                                                                                                                                                                                       | капс только в бейджах и ярлыках над заголовком, с разрядкой                                                                  |
| Масштаб при нажатии              | 0.96 (ui-skills), 0.97 (emil)                                                                                                                                                                                                                                                                                                             | около 0.97, не меньше 0.95                                                                                                   |
| Стаггер | около 100ms (ui-skills), 30–80ms (emil), без ограничений ([figma-use-motion](https://github.com/figma/mcp-server-guide/tree/main/skills/figma-use-motion)), весь каскад до 500ms (hallmark), 20–40ms у списка длиннее десяти (ui-ux-pro-max) | 50–100ms, весь каскад до 500ms, только на первом показе |
| Потолок длительности | 300ms (emil), модалка и шторка 200–500ms (emil, [animate](https://github.com/emilkowalski/skills/tree/main/skills/animate)), до 700ms (gstack, [figma-use-motion](https://github.com/figma/mcp-server-guide/tree/main/skills/figma-use-motion)) | 300ms для отклика, шторка до 500ms, длиннее — для декоративного раскрытия с причиной |
| Кривая выхода                    | ease-in (gstack, [micro-interaction](https://github.com/iart-ai/web-animation-skills/tree/main/skills/micro-interaction)), ease-out (emil, krehel)                                                                                                                                                                                        | выход короче входа                                                                                                           |
| Пружина | не для откликов (ui-skills), пресеты-пружины ([figma-use-motion](https://github.com/figma/mcp-server-guide/tree/main/skills/figma-use-motion)), двойной перелёт у тумблера (transitions), отскок всегда 0 (krehel) | не для откликов, да для жестов; тумблер без перелёта |
| Цель нажатия                     | 44px ([Apple HIG](https://developer.apple.com/design/human-interface-guidelines/buttons), ui-skills), 28px минимум на iOS ([Apple HIG](https://developer.apple.com/design/human-interface-guidelines/accessibility)), 24px AA ([WCAG 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)), 40px десктоп (krehel) | 44px на таче, минимум 28px, зона шире видимого                                                                               |
| Уровни высоты                    | 3–4 (dsc), ровно 3 (nick)                                                                                                                                                                                                                                                                                                                 | три                                                                                                                          |
| Основной текст                   | не меньше 16px везде (gstack), 16px только в полях на мобильном (krehel)                                                                                                                                                                                                                                                                  | основной текст 16px, плотный рабочий интерфейс вправе 14px, поле ввода на мобильном 16px                                     |
| Подложка модалки                 | сплошная (ui-skills), полупрозрачный материал (apple)                                                                                                                                                                                                                                                                                     | сплошная; материал на малых поверхностях с `prefers-reduced-transparency`                                                    |
| Загрузка                         | скелетон (ui-skills), прошлый вид (anthropic)                                                                                                                                                                                                                                                                                             | скелетон при первой загрузке, прошлый вид при обновлении                                                                     |
| Обрезка текста                   | `truncate` (ui-skills), обрезанный текст — ошибка (anthropic)                                                                                                                                                                                                                                                                                | сначала сократить; обрезать в тесном месте, если полный текст доступен в одно нажатие; затухание предпочтительнее многоточия |
| Табличные цифры у крупного числа | везде (ui-skills), не у одиночного крупного (anthropic)                                                                                                                                                                                                                                                                                   | табличные в колонках и меняющихся числах, у одиночного крупного цифры разной ширины                                          |
| Тонированные нейтрали            | признак ИИ ([frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)), признак выбора (artifact-design)                                                                                                                                                                                                   | нейтраль выбирается; тон допустим, если выбран под бренд                                                                     |
| Системный шрифт                  | норма (apple), слоп (gstack)                                                                                                                                                                                                                                                                                                              | законен в рабочем интерфейсе, на маркетинговой странице шрифт выбирается                                                     |
| `cursor: pointer`                | на всём кликабельном (gstack), системное поведение ([Tailwind v4](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor))                                                                                                                                                                                             | системное поведение, рука только у ссылок                                                                                    |
| Нижняя навигация на мобильном    | конвенции наверху (gstack), частое внизу (nick)                                                                                                                                                                                                                                                                                           | в приложении вкладки внизу, на сайте сверху; вниз, когда по разделам ходят часто                                             |
| Бургер                           | допустим (gstack), не прятать (birman)                                                                                                                                                                                                                                                                                                    | только когда меню не помещается, главное действие никогда                                                                    |
| Согласованность и ясность        | консистентность (nick), ясность важнее ([Steve Krug](https://sensible.com/dont-make-me-think/))                                                                                                                                                                                                                                           | согласованность по умолчанию, отступление ради заметной ясности с причиной                                                   |
| Исчезновение успеха              | успех исчезает сам (gstack), время не ограничивает ([WCAG 2.2.1](https://www.w3.org/WAI/WCAG22/Understanding/timing-adjustable.html))                                                                                                                                                                                                     | информационный тост 4–5s с паузой, всё с действием или ошибкой — до закрытия                                                 |
| Пустое состояние                 | одно действие (ui-skills), рабочий вид с примером (anthropic)                                                                                                                                                                                                                                                                             | образец будущего содержимого и одно действие                                                                                 |
| Брейкпоинты                      | стандартные значат «не выбирали» ([explain-interface](https://github.com/jakubkrehel/skills/tree/main/skills/explain-interface)), Tailwind-first                                                                                                                                                                                          | брейкпоинты Tailwind для рамки страницы, компоненты по контейнеру                                                            |
| Близость и подложка              | близость сильнее рамки (nick), общая подложка сильнее близости ([Stephen Palmer](https://e-edu.nbu.bg/pluginfile.php/951829/mod_resource/content/1/Stephen-Palmer%20-%20Common%20region%20-%20A%20new%20principle%20of%20perceptual%20grouping%201992.pdf))                                                                               | сначала пространство; подложка, когда пространства не хватает                                                                |
| Кнопки диалога                   | главная справа (конвенция платформ), главная первой по ходу чтения (nick)                                                                                                                                                                                                                                                                 | главная первой по ходу чтения и акцентная, в форме и в диалоге; отмена в стороне с обводкой или без фона                     |
| Удаление                         | undo (birman), подтверждение (nick)                                                                                                                                                                                                                                                                                                       | undo для обратимого, подтверждение для необратимого                                                                          |
| Цвет части заголовка             | слоп (anthropic), приём в перебивках (nick)                                                                                                                                                                                                                                                                                               | один раз на страницу с причиной, не шаблоном                                                                                 |
| Появление при прокрутке          | содержимое видно в покое (anthropic), появление по вьюпорту (nick)                                                                                                                                                                                                                                                                           | начинается из видимого, играет один раз, не на каждом блоке                                                                  |
| Автофокус                        | без автофокуса на мобильном (gstack), фокус на следующее поле после выбора (nick)                                                                                                                                                                                                                                                         | только когда человек пришёл вводить                                                                                          |
| Порядок проектирования           | mobile first, desktop first при большом объёме (nick)                                                                                                                                                                                                                                                                                     | компонент сразу проектируется для всех ширин контейнера, начиная с десктопа                                                  |
| Когда утверждать концепцию       | на ключевых экранах сразу (nick), в конце широкого поиска (complex-designer)                                                                                                                                                                                                                                                              | концепция складывается к концу, продукт прорабатывается целиком и слоями                                                     |
| Версии знака                     | несколько версий и упрощённая на малом размере (nick), одна универсальная (complex-designer)                                                                                                                                                                                                                                              | одна основная версия, упрощённая только там, где основная не читается                                                        |
| Углы экрана                      | края — бесконечные цели ([закон Фиттса](https://www.cs.princeton.edu/courses/archive/fall08/cos436/FittsJEP1954.pdf)), важное не в углах ([Figma](https://www.figma.com/resource-library/fitts-law/))                                                                                                                                     | для курсора края удобны, на таче углы хуже всего                                                                             |
| Ссылка в новой вкладке           | в той же вкладке (конвенция), из инструкции в новой (nick)                                                                                                                                                                                                                                                                                | в той же; в новой, когда уход сломает начатое                                                                                |
| Посещённые ссылки                | различать всегда (gstack), только в тексте (nick)                                                                                                                                                                                                                                                                                         | только ссылки в тексте                                                                                                       |
| Шаг шкалы кеглей в рабочем интерфейсе | 1.125–1.2 без `clamp` (impeccable, режим operate); меньше 1.25 — плоская иерархия (impeccable, детектор); примеры 1.25 и 1.333 (gstack, krehel) | |
| Чистый чёрный и белый | без `#000` и `#fff` (taste); тонированный почти чёрный — примета генератора (anthropic) | без запрета: цвета текста и фона выбираются по контрасту и теме |
| Число состояний темы | светлая, тёмная и системная (krehel, vercel); две: «как в системе» и «наоборот», потому что из трёх две всегда выглядят одинаково (chrome) | три |
| Слои токенов | два: примитивы и семантика (krehel, figma); третий слой компонентных токенов (ui-ux-pro-max) | |
