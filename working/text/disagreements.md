# Расхождения источников в тексте

Здесь собраны места, где источники советуют разное, и что выбрано. Правило в скилле уже записано по выбранному варианту. Строка с пустой колонкой «Выбрано» — спор, который ещё не решён, и правило по нему не пишется, пока выбора нет.

| Вопрос                           | Источники                                                                                                                                                                                                                                                                                                                                 | Выбрано                                                                                                                      |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Регистр                          | Title Case (vercel), как в предложении (ui-skills, nick)                                                                                                                                                                                                                                                                                  | как в обычном предложении, с прописной только первое слово и имена                                                           |
| Знак процента | с отбивкой «45 %» (milchin, bezukladnikov, ГОСТ 8.417), слитно «45%» (nick, веб-практика) | слитно «45%» |
| Знак тире | «—» с пробелами, «–» в диапазоне без пробелов (milchin, nick); «–» с пробелами везде, «—» не ставится (bezukladnikov) | «—» с пробелами по Мильчину, «–» только в диапазоне |
| Неразрывный пробел | в исходнике сущностью `&nbsp;` (bezukladnikov); в исходнике обычный пробел, неразрывный ставит шаблон при выводе (nick) | ставит шаблон |
| Обрывки ради ритма | назывные обрывки законны (bezukladnikov); два обрывка подряд правятся всегда, один отрезанный обрывок ставится раз на 750 слов (nick) | по правилам «Рубленые фразы» и «Парцелляция и ударная концовка» |
| «Является» в определении | в определении законно (bezukladnikov); меняется на тире или «это» (nick) | тире или «это», глагол остаётся, когда добавляет смысл |
| Место знака валюты | после числа «500 $» (milchin), по норме валюты «$500» и «500 €» (nick) | по норме валюты: «$500» перед числом, «500 €» после |
| Разбивка разрядов | с пятизначных (milchin), с четырёхзначных (milchin в пересказе скилла, nick) | с четырёхзначных |
| Пунктуация перечня | регистр и знак по маркеру (milchin), все подписи с заглавной (nick) | все подписи с заглавной |
| Место главного во фразе | смысловое ударение в конце (nora-gal), главное в начало заголовка и кнопки (nick, copyhackers) | главное слово близко к началу заголовка и кнопки |
| Тире в тексте | ни одного, если его нет в образце автора (wiki-ai), одно тире или двоеточие на предложение (nick) | одно на предложение: в русском тире ставится по грамматике, на месте связки и пропуска; sepia тоже считает частоту тире свойством площадки, а не общим запретом |
| Порядок проверки | сначала приёмы и шум, потом текст целиком (nick); сначала самый глубокий слой (sepia); от дешёвого к дорогому (unslop) | |
| Горизонтальная линия и эмодзи в заголовке | признаки машины (wiki-ai, humanizer, nick); не признаки: линия есть в 60% человеческих постов и ни в одном посте ассистента (quiron) | правила остаются: линия и эмодзи мешают читателю независимо от того, кто писал |
| Пассив | правится при каждом вхождении (nick); у ассистентов его меньше, чем у людей (quiron); слабый признак сам по себе (humanizer) | правило остаётся: оно о скрытом действующем лице, а не о детекции |
| «Let me know» в конце письма | след чат-бота (wiki-ai); давняя человеческая формула прощания (quiron) | |
| Риторический вопрос и «не X, а Y» | признаки машины (wiki-ai, pangram, russell); по замерам на корпусах не отличают машину от человека (ilyautov) | правила остаются: они обоснованы ценой для читателя, а не детекцией |
| «Ложный диапазон» и «Ротация синонимов» | признаки машины (humanizer до версии 3.0.0); Wikipedia ложный диапазон больше не называет, а разнообразие словаря относит к историческим признакам (wiki-ai, humanizer 3.0.0); разнообразие словаря у моделей выше, чем у людей (quiron) | правила остаются: оба приёма мешают читателю, ключей источников у них нет |
| Повтор в справке | у каждой мысли одно место (nick); статья справки повторяет текст ошибки и первый шаг, потому что человек открывает её из поиска отдельно (samber, принцип ARID у Write the Docs) | узкое исключение: статья справки повторяет текст ошибки и первый шаг, длинная процедура остаётся в одном месте |
| Заглушка в примере кода | в угловых скобках `<YOUR_API_KEY>` (samber); `your_access_token_here`, которую выделяет двойной щелчок, и никогда `<TOKEN>` (vercel) | |
